A 95-million-parameter language model in one small file. Open weights, no tokenizer, no network,
English and Russian — trained from scratch on a single 16 GB card, in the format it ships in.

## What it is

The input is the file itself — 256 symbols, no vocabulary, nothing lost in a translation to token
ids, and no word the model can never see. It trains **in the format it ships in**: every forward
pass sees `−α, 0, +α` from the first step, and an anneal pulls the projection onto those three
levels. The download is the network, not an approximation of one.

The bet is density: how much model fits on one card, in one file, in one night. The budget is fixed
first — one consumer GPU, days, one downloadable file — and then the question is what fits inside
it.

## How to read a number here

Every result is three things: **a loss, a window, a budget**. A bits-per-byte figure without the
held-out window it was measured on, and the bytes of training that preceded it, is an anecdote.
Where a claim has no run behind it, this documentation says so and names what would settle it.
