01what it is

A language model that is a file, not a service.

The input is the file itself — 256 symbols, no vocabulary, nothing lost in a translation to token ids. It learns in the format it ships in: every weight is −1, 0 or +1 from the first step, so the download is the network and not an approximation of one.

input
raw bytes · 256 symbols · no tokenizer
weights
ternary from step 0, quantized-aware, annealed
budget
one RTX 5070 Ti, 16 GB, days — not a cluster
languages
English and Russian, in the same 256 symbols

The first thing to say, not the last: a 95M model knows less than a 30B one, and no architecture closes a three-order-of-magnitude gap in data. What you are buying is the file, the control and the privacy — not the knowledge.

04the licence

Apache-2.0. Weights, code and recipe.

No key, no seat, no call home. A paid licence on a file is not defensible when a free model of the same class sits next to it, so the file is free — and what is sold around it is installation, fine-tuning and responsibility.

weightsThe ternary file, downloadable and redistributable.
codeThe trainer, the packer, the server. Read it before you trust it.
recipeEvery config, every measurement, including the ones that failed.
